- ? Fechas de viaje están en el pasado

- ? PlazasDisponibles inicializadas en 50

### Prevención de Duplicados

- ? No se crean opiniones duplicadas del mismo usuario en el mismo paquete
- ? Verificación de usuarios existentes antes de seed
- ? Cada usuario solo puede opinar una vez por paquete

## ?? Comandos Útiles

```bash
# Eliminar base de datos
dotnet ef database drop --project SoloUnClick.Infrastructure --startup-project SoloUnClick.web

# La aplicación recreará y seederá automáticamente al iniciar
dotnet run --project SoloUnClick.web
```
